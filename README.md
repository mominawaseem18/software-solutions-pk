# ESASOFT – Software Solutions

A modern and responsive software solutions website built with React.js. ESASOFT provides digital solutions for businesses through custom software development, POS and ERP systems, web development, mobile applications, and more.

##  Live Website

[Visit ESASOFT – Software Solutions](https://software-solutions-pk.netlify.app/)

##  About the Project

ESASOFT is a professional software solutions website designed to showcase business software products and services. The website provides information about different software solutions, company services, industries, and contact options.

The project focuses on creating a clean, modern, and user-friendly interface using React.js.

##  Location API

The website includes a Location Selector that allows users to select their location through an API.

### Location Features

* Select Country
* Select State / Province
* Select City
* Fetch location data using API
* Dynamic dropdown selection
* Continue button for location selection

The location selector helps users choose their country, state, and city in an easy and user-friendly way.

##  Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd SOFTWARE
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm start
```

The project will run on the local development server.
